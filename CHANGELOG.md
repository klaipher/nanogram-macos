- Identity `org.klaipher.Nanogram` (share extension `org.klaipher.Nanogram.MacShare`, team YGTMYL879P, one app group); Telegram's update, crash-bot and store endpoints removed. Apple Silicon only, macOS 15+.
- Two editions from one codebase: `mas` (App Store/TestFlight, sandboxed, no Sparkle) and `direct` (Developer ID, notarized dmg, Sparkle 2.10.1 from klaipher/nanogram-releases).
- Settings layer `nanogram/Nanogram.xcconfig` + `nanogram/editions/*.xcconfig`; Release: ThinLTO, `-O3`, dead-code stripping, whole-module Swift, launch order file, exclusivity checks off in Release (M17), editions check, buildcheck.

- Telegram core moved to `submodules/telegram-ios` from klaipher/nanogram `mac/core` (history-free); FFmpeg 9.0.2, libvpx/dav1d/libopus build fixes (M15, M19, H10, H15).
